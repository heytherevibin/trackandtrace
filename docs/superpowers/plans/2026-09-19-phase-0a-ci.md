# Phase 0 · Part A: CI implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** GitHub checks every pull request into `main` and every push to `main`: types, lint, unit and integration tests, a production build, and the Playwright suite. A weekly audit also runs on production dependencies.

**Architecture:** Two GitHub Actions workflows:

- `ci.yml` runs the jobs `verify` and `e2e`, which later become required on `main`.
- `audit.yml` runs `npm audit`, on a schedule and when the dependency files change.

Neither uses a secret, and every test runs on the sample-data fixture. A Vitest contract test holds the policy (no secrets, read-only token, Node 24, actions pinned to a commit), so a later edit can't quietly break it.

**Tech stack:** GitHub Actions on `ubuntu-24.04`; Node 24 (the Vercel project runs Node.js 24.x); npm; Vitest 3; Playwright 1.62 (Chromium only); Next 16 `next typegen`.

**Spec:** `docs/superpowers/specs/2026-09-18-phase-0-foundations-design.md`, part A.

## Global Constraints

- Node **24** everywhere in CI. `vercel project inspect trakline` reports "Node.js Version 24.x".
- **No secrets in CI.** Every test runs on the sample-data fixture. Workflows never reference `secrets.`.
- Token permissions are `contents: read` at workflow level.
- Every `uses:` is pinned to a full 40-character commit SHA, with the version in a comment. SHAs checked on 2026-09-19:
  - `actions/checkout` v7.0.1 = `3d3c42e5aac5ba805825da76410c181273ba90b1`
  - `actions/setup-node` v7.0.0 = `820762786026740c76f36085b0efc47a31fe5020`
  - `actions/cache` v6.1.0 = `55cc8345863c7cc4c66a329aec7e433d2d1c52a9`
  - `actions/upload-artifact` v7.0.1 = `043fb46d1a93c77aae656e7c1c64a875d1fc6a0a`
- The `verify` job runs `npm ci`, then typecheck, lint, `test:unit` (which includes `tests/integration`), then `build`. The build runs with no env vars, the same as a fresh checkout.
- The `e2e` job runs Playwright Chromium with system libraries. Browsers are cached by Playwright version. It runs `npx playwright test` in fixture mode (desktop and mobile, axe scans), and uploads the HTML report only on failure.
- `audit` runs `npm audit --omit=dev --audit-level=high` weekly and when `package.json` or `package-lock.json` change. It fails only on high or critical advisories in production dependencies.
- `concurrency` cancels superseded pull-request runs. Runs on `main` always finish.
- `main` requires `verify` and `e2e` after the first green run. That is a GitHub setting, changed **only with the user's go-ahead**.
- Conventional commits. **No `Co-Authored-By` trailer** (the user's CLAUDE.md). Files stay under 500 lines.

**Two deliberate adjustments to the spec's wording:**

- **Triggers.** The spec says "every push, and pull requests into `main`". Running on both would check each commit of an open PR twice, because it is both a push and a PR update. So the triggers are pull requests into `main`, pushes to `main`, and a manual run (`workflow_dispatch`) for any branch. Every change still passes CI before and after it lands.
- **Workflow files.** The spec says "one workflow". The audit's own triggers (a schedule, and only dependency-file changes) need a second file, because GitHub filters paths per workflow, not per job.

- [x] **Step 1: Write the failing contract test**

`tests/unit/ci-workflows.contract.test.ts`:

```ts
import { existsSync, readFileSync } from "node:fs";
import { join } from "node:path";
import { describe, expect, it } from "vitest";

// CI policy from the Phase 0 spec, part A: no secrets, a read-only token,
// Vercel's Node version, and actions pinned to a commit.

const DIR = join(process.cwd(), ".github/workflows");
const FILES = ["ci.yml"] as const;

function read(name: string): string {
  const path = join(DIR, name);
  return existsSync(path) ? readFileSync(path, "utf8") : "";
}

const all = (text: string, pattern: RegExp) => [...text.matchAll(pattern)].map((m) => m[1] ?? "");

describe.each(FILES)("%s", (name) => {
  const text = read(name);

  it("exists", () => {
    expect(text).not.toBe("");
  });

  it("never reads a secret: every test runs on the sample-data fixture", () => {
    expect(text).not.toMatch(/secrets\./);
  });

  it("gives the token read access only", () => {
    expect(text).toMatch(/^permissions:\n {2}contents: read$/m);
  });

  it("runs the Node version Vercel runs (24.x)", () => {
    const versions = all(text, /node-version:\s*(\S+)/g);
    expect(versions.length).toBeGreaterThan(0);
    expect(new Set(versions)).toEqual(new Set(["24"]));
  });

  it("pins every action to a full commit", () => {
    const uses = all(text, /uses:\s*(\S+)/g);
    expect(uses.length).toBeGreaterThan(0);
    for (const action of uses) expect(action).toMatch(/^[\w.-]+\/[\w.-]+@[0-9a-f]{40}$/);
  });
});

describe("ci.yml", () => {
  const ci = read("ci.yml");

  it("has the two jobs main will require", () => {
    expect(ci).toMatch(/^ {2}verify:$/m);
    expect(ci).toMatch(/^ {2}e2e:$/m);
  });

  it("verifies in order: types, lint, unit and integration tests, production build", () => {
    const at = ["npm run typecheck", "npm run lint", "npm run test:unit", "npm run build"].map((step) => ci.indexOf(step));
    expect(at.every((i) => i >= 0)).toBe(true);
    expect([...at].sort((a, b) => a - b)).toEqual(at);
  });

  it("runs the browser suite and keeps its report only when it fails", () => {
    expect(ci).toContain("npx playwright test");
    expect(ci).toMatch(/if: failure\(\)\n\s+uses: actions\/upload-artifact@/);
  });
});
```

- [x] **Step 3: Write `.github/workflows/ci.yml`**

```yaml
# Checks every pull request into main and every push to main.
# No secrets: every test runs on the sample-data fixture.
name: CI

on:
  pull_request:
    branches: [main]
  push:
    branches: [main]
  workflow_dispatch:

permissions:
  contents: read

concurrency:
  group: ci-${{ github.ref }}
  cancel-in-progress: ${{ github.event_name == 'pull_request' }}

env:
  NEXT_TELEMETRY_DISABLED: "1"

jobs:
  verify:
    runs-on: ubuntu-24.04
    timeout-minutes: 15
    steps:
      - uses: actions/checkout@3d3c42e5aac5ba805825da76410c181273ba90b1 # v7.0.1
      - uses: actions/setup-node@820762786026740c76f36085b0efc47a31fe5020 # v7.0.0
        with:
          node-version: 24
          cache: npm
      - run: npm ci
      - run: npm run typecheck
      - run: npm run lint
      - run: npm run test:unit
      - run: npm run build

  e2e:
    runs-on: ubuntu-24.04
    timeout-minutes: 20
    steps:
      - uses: actions/checkout@3d3c42e5aac5ba805825da76410c181273ba90b1 # v7.0.1
      - uses: actions/setup-node@820762786026740c76f36085b0efc47a31fe5020 # v7.0.0
        with:
          node-version: 24
          cache: npm
      - run: npm ci
      - name: Read the Playwright version
        id: playwright
        run: echo "version=$(node -p "require('@playwright/test/package.json').version")" >> "$GITHUB_OUTPUT"
      - name: Cache Playwright browsers
        id: browsers
        uses: actions/cache@55cc8345863c7cc4c66a329aec7e433d2d1c52a9 # v6.1.0
        with:
          path: ~/.cache/ms-playwright
          key: playwright-${{ runner.os }}-${{ steps.playwright.outputs.version }}
      - name: Install Chromium and its system libraries
        if: steps.browsers.outputs.cache-hit != 'true'
        run: npx playwright install --with-deps chromium
      - name: Install Chromium's system libraries
        if: steps.browsers.outputs.cache-hit == 'true'
        run: npx playwright install-deps chromium
      - run: npx playwright test
      - name: Keep the report
        if: failure()
        uses: actions/upload-artifact@043fb46d1a93c77aae656e7c1c64a875d1fc6a0a # v7.0.1
        with:
          name: playwright-report
          path: |
            playwright-report/
            test-results/
          retention-days: 7
```

- [x] **Step 3: Write `.github/workflows/audit.yml`**

```yaml
# Production dependencies only; fails on high or critical advisories.
# Runs weekly and when the dependency files change, so a new advisory
# never blocks unrelated work.
name: Dependency audit

on:
  pull_request:
    branches: [main]
    paths: [package.json, package-lock.json]
  push:
    branches: [main]
    paths: [package.json, package-lock.json]
  schedule:
    - cron: "30 3 * * 1" # Mondays, 09:00 IST
  workflow_dispatch:

permissions:
  contents: read

jobs:
  audit:
    runs-on: ubuntu-24.04
    timeout-minutes: 5
    steps:
      - uses: actions/checkout@3d3c42e5aac5ba805825da76410c181273ba90b1 # v7.0.1
      - uses: actions/setup-node@820762786026740c76f36085b0efc47a31fe5020 # v7.0.0
        with:
          node-version: 24
      - run: npm audit --omit=dev --audit-level=high
```

`npm audit` reads `package-lock.json`, so the job needs no `npm ci`.
